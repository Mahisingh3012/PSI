# Project library: "Drishti" (Jan to Sep 2026)

FICTIONAL HACKATHON MATERIAL. Panscience Hackathon, 31 Oct 2026.
Ardent Cement Works Ltd, its Bhadrapur unit, every person, number, purchase order and event in this library are invented.
PredCo and its product names are used as the vendor for realism only; this project did not happen.
Do not upload this library to public websites.

## What this is

Everything a vendor team typically has after an eight-month enterprise project: the first email, the scoping calls, the
signed requirements, purchase orders, change requests, the delivery tracker, incidents, three review meetings, email
threads, the code repository, raw metric exports, client feedback, media, and the client's public footprint.

It is messy on purpose, as real projects are: documents disagree, scope changed, people changed, numbers were measured
in different ways at different times, and not everything that improved was caused by the vendor.

Dates are in IST. Money is in Indian rupees (1 lakh = 100,000; 1 crore = 10,000,000), before GST unless stated.
